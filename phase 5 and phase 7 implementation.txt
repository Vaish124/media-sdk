● Root cause

  sdk.emit({ type: 'download', ... }) in packages/media-core/src/sdk.ts only
  pushes an event through EventEmitter — the SDK's only built-in listener is a
  console.log (that's what shows up in the Event Log via useMediaEvents).
  Nothing in media-core, media-react, or media-ui-react ever touches document,
  triggers a browser download, or fetches image bytes — that's by design (per
  wiring-data/SKILL.md, useMediaSDK/emit is documented as being "for telemetry,"
  and the headless UI package is explicitly forbidden from touching the DOM
  beyond ARIA/refs). So the old handleDownload in LightboxView.tsx fired the
  event and stopped there — correct telemetry, no actual file transfer.

  Fix — apps/web/src/components/LightboxView.tsx

  Kept the sdk.emit(...) call exactly as before, and added the actual download
  after it:
  1. fetch(activeItem.src.original) — full-resolution image, no API key involved
  (Pexels' CDN is public and sends Access-Control-Allow-Origin: *, confirmed by
  curl/node-fetch test).
  2. Convert the response to a Blob, wrap it in URL.createObjectURL, and click a
  temporary <a download> element — this is the reliable cross-origin download
  pattern (a plain <a href="...pexels.com/..."> wouldn't work because Pexels
  serves images with Content-Disposition: inline, so the browser would just
  navigate/open the image instead of saving it).
  3. Revoke the object URL and remove the temp element immediately after.
  4. Wrapped in try/catch/finally: on failure, shows "Download failed. Please 
  try again." via a role="alert" message next to the button; the Download button
  also shows Downloading… and disables itself mid-request so you can't
  double-fire it. Both the error and in-flight state reset automatically when
  you navigate to a different photo.

  No new dependencies — everything used (fetch, Blob, URL.createObjectURL, <a>)
  is a native browser API. No API key is touched anywhere in this path (the
  Pexels CDN image URLs require no auth, unlike the /v1/... search API).

  Also added .downloadBtn:disabled and .downloadError rules to
  apps/web/src/styles/lightbox.module.css.
